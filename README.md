# 🕹️ Arcade de Sistemas - Plataforma Educativa Interactiva

Plataforma web gamificada diseñada para la enseñanza de conceptos de Ingeniería en Sistemas, desarrollada con un diseño moderno (Glassmorphism), animaciones dinámicas y gestión de sesiones en tiempo real.

---

## 🚀 Instrucciones de Instalación para Desarrollo Local

Dado que el proyecto utiliza **PHP** para la lógica de los juegos y la gestión de sesiones, es necesario ejecutarlo a través de un servidor local (como XAMPP). Sigue estos pasos para probarlo en tu PC:

1. **Clonar o Descargar:** 
   Haz clic en el botón verde **"Code"** en la parte superior de este repositorio y selecciona **"Download ZIP"**.
   
2. **Ubicación del Servidor:** 
   Descomprime el archivo ZIP y **copia la carpeta completa** dentro del directorio raíz de tu servidor local de XAMPP:
   ```text
   C:\xampp\htdocs\
